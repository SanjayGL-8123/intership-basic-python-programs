# Function Definition and Invocation (`function.py`)

A beginner example demonstrating how to declare and call functions in Python.

---

## 📋 Overview

Functions are reusable blocks of code that perform a specific task. They help keep code modular, readable, and DRY (Don't Repeat Yourself).

---

## 🛠️ Requirements & Dependencies

- **Python Version:** Python 3.x
- **External Libraries:** None (standard library only)

---

## 🚀 How to Run

```powershell
python function.py
```

---

## 🔍 Code Breakdown

```python
def callmyfunc():
    print("this is function new call")

callmyfunc()
callmyfunc()
callmyfunc()
```

### Key Concepts:
- `def`: The keyword used to define a function in Python.
- `callmyfunc()`: The name of the function followed by parentheses.
- Function Call: Calling `callmyfunc()` executes the indented block of code inside the function definition. Here, it is called 3 consecutive times.

---

## 💡 Output

```text
this is function new call
this is function new call
this is function new call
```
