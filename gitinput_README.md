# Console Input and Concatenation (`gitinput.py`)

A minimal beginner example illustrating how to read string input from the terminal and concatenate strings in Python.

---

## 📋 Overview

Demonstrates Python's built-in `input()` function and basic string formatting / concatenation using the `+` operator.

---

## 🛠️ Requirements & Dependencies

- **Python Version:** Python 3.x
- **External Libraries:** None (standard library only)

---

## 🚀 How to Run

```powershell
python gitinput.py
```

---

## 🔍 Code Breakdown

```python
name = input("enter the name :")
print("your name is :" + name)
```

### Key Concepts:
- `input("enter the name :")`: Displays the prompt and pauses execution until the user presses Enter.
- `"your name is :" + name`: Combines the string literal with the variable `name`.

---

## 💡 Example Run

```text
enter the name :Antigravity
your name is :Antigravity
```
